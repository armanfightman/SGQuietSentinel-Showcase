# SGQuietSentinel (SGQS)

**Локальный мониторинг и диагностика Windows**

SGQS — разрабатываемое настольное приложение на C# и WinUI 3. Оно показывает состояние компьютера, помогает оценить влияние процессов на нагрузку и предоставляет инструменты для разбора недавних замедлений.

**Статус:** активная разработка. Ниже представлены реальные экраны обычной сборки `DevUnpackaged x64` от 15 октября 2026 года. Это **не опубликованный релиз** и не подтверждение приёмки beta `0.5.0.0`.

## Реализованные направления

- **Системные метрики:** наблюдение за CPU, оперативной памятью, дисками и сетевой активностью.
- **GPU:** сбор данных с использованием DXGI и счётчиков PDH. Интерпретация нагрузки зависит от адаптера и требует дополнительной проверки на разных конфигурациях Windows.
- **Процессы:** отображение влияния приложений на использование процессора и памяти. SGQS не предназначен для завершения чужих процессов.
- **Разбор замедлений:** анализ доступных локальных наблюдений с учётом ограничений данных.
- **Настройки:** оформление, поведение окна и работа в системном трее.

## Архитектура и инженерные решения

| Компонент | Назначение |
|---|---|
| `SGQuietSentinel.App` | Интерфейс WinUI 3, экраны и взаимодействие с пользователем |
| `SGQuietSentinel.Core` | Модели измерений, обработка состояний, расчёты и логика диагностики |
| `SGQuietSentinel.Windows` | Получение системных показателей через API Windows |
| `SGQuietSentinel.Tests` | Автоматизированные проверки логики, моделей и сценариев |

Отдельное внимание уделяется достоверности данных: отсутствие измерения не должно отображаться как реальный ноль. Для расширенной диагностики прорабатываются монотонная временная модель, отмена операций и гарантированное освобождение ресурсов.

**Технологии:** C#, .NET 8, WinUI 3, Windows App SDK, DXGI, PDH, MSTest, Git.
